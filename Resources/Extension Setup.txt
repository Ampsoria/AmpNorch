AmpNotch — คู่มือติดตั้งส่วนขยาย Ampsoria Connected
=================================================

ส่วนขยายนี้ใช้แสดงชื่อเพลง ปก และควบคุมสื่อที่เล่นในเบราว์เซอร์จาก notch
ถ้าใช้ Apple Music หรือ Spotify แบบแอปบน Mac ไม่ต้องติดตั้งส่วนขยาย

รองรับเบราว์เซอร์ตระกูล Chromium เช่น Chrome, Edge, Brave และ Arc
แพ็กเกจนี้ไม่ใช่ส่วนขยายสำหรับ Safari หรือ Firefox

1. ติดตั้งและเปิด AmpNotch
--------------------------
• ลาก AmpNotch.app จาก DMG ไปไว้ใน Applications แล้วเปิดแอปจากที่นั่น
• ครั้งแรกจะมีหน้า Set up AmpNotch ให้เลือกสิทธิ์เฉพาะฟีเจอร์ที่จะใช้
• หากใช้แต่เพลงจากเบราว์เซอร์ ไม่จำเป็นต้องเปิด Automation ของ Music/Spotify
• กด Done / Set up later เพื่อข้าม และกลับมาที่ Settings → Setup & permissions… ได้
• ให้ AmpNotch ทำงานอยู่ระหว่างใช้งานส่วนขยาย
• คลิกไอคอน AmpNotch ใน menu bar → Settings…

2. เตรียมโฟลเดอร์ส่วนขยายไว้ในเครื่อง
---------------------------------------
• ใน Settings หาหัวข้อ Music & browser แล้วกด Extension folder
• Finder จะเปิดโฟลเดอร์ BrowserExtension ที่มี manifest.json
• ใน Finder กด Command + ลูกศรขึ้น เพื่อเห็นโฟลเดอร์ BrowserExtension
• คัดลอกทั้งโฟลเดอร์ไปไว้ใน Documents ของคุณ
• เก็บโฟลเดอร์นี้ไว้ ห้ามลบหรือย้ายหลังจากติดตั้งส่วนขยาย
  ไม่ควรเลือกโฟลเดอร์บน DMG เพราะจะใช้ไม่ได้เมื่อถอดดิสก์ออก

3. โหลดส่วนขยายในเบราว์เซอร์
-----------------------------
• Chrome: พิมพ์ chrome://extensions ในแถบที่อยู่แล้วกด Enter
• Edge: พิมพ์ edge://extensions
• Brave: พิมพ์ brave://extensions
• Arc: เปิดหน้าจัดการ Extensions ของเบราว์เซอร์

จากนั้น:
1) เปิด Developer mode (โหมดนักพัฒนา)
2) กด Load unpacked (โหลดส่วนขยายที่แตกไฟล์แล้ว)
3) เลือกโฟลเดอร์ BrowserExtension ที่คัดลอกไว้ใน Documents
   ต้องเลือกโฟลเดอร์ที่มี manifest.json อยู่ด้านใน ไม่ใช่เลือกไฟล์นั้น
4) ตรวจว่ามี Ampsoria Connected และสวิตช์เปิดใช้งานอยู่
5) เปิดเมนู Extensions ในแถบเครื่องมือ แล้วปักหมุด Ampsoria Connected
   หากเบราว์เซอร์มีตัวเลือกปักหมุด จะช่วยให้เปิดหน้าจับคู่ได้ง่ายขึ้น

4. จับคู่กับ AmpNotch บนเครื่องของคุณ
-------------------------------------
1) กลับไป Settings ของ AmpNotch → Music & browser
2) กด Copy browser pairing code
3) คลิกไอคอน Ampsoria Connected ในเบราว์เซอร์
4) วางรหัสในช่อง Pairing code
5) กด Connect to AmpNotch
6) รอข้อความ Connected to AmpNotch

ใช้รหัสจาก AmpNotch บนเครื่องเดียวกัน ไม่ใช้รหัสของผู้ที่ส่ง DMG มาให้
ไม่ต้องสมัครบัญชี และไม่ต้องส่ง pairing code ให้คนอื่น

5. ทดลองเล่นเพลง
-----------------
• รีโหลดหน้าเว็บเพลง/วิดีโอที่เปิดค้างไว้ หรือเปิดหน้าใหม่
• เริ่มเล่นเพลง เช่น วิดีโอบน YouTube
• notch ควรแสดงชื่อเพลงและปกเมื่อเว็บไซต์เปิดเผยข้อมูลนั้น
• คลิก notch แล้วลองเล่น/หยุด หากมีหลายแอปหรือหลายแท็บ:
  เปิดเมนูสามจุดใน notch แล้วเลือกแหล่งเพลงที่ต้องการ
• การเลื่อนเวลาและปุ่มข้ามเพลงขึ้นอยู่กับความสามารถของเว็บไซต์
  บางเว็บหรือวิดีโอที่ฝังจากเว็บไซต์อื่นอาจควบคุมไม่ได้

กราฟเสียงจริงเป็นการตั้งค่าแยกจากส่วนขยาย:
เปิด Settings → Live audio waveform และอนุญาต System Audio Recording
บน macOS 14.2 ขึ้นไป แอปประมวลผลเสียงในเครื่อง ไม่บันทึกหรืออัปโหลดเสียง

แก้ปัญหาเบื้องต้น
-----------------
• Not connected: ตรวจว่า AmpNotch เปิดอยู่ คัดลอกรหัสใหม่จากเครื่องนี้
  แล้วกด Connect to AmpNotch อีกครั้ง
• เชื่อมต่อแล้วแต่ไม่มีเพลง: เปิดสวิตช์ส่วนขยาย รีโหลดเว็บ แล้วเริ่มเล่นสื่อ
  ตรวจสิทธิ์เข้าถึงเว็บไซต์ของส่วนขยาย และเลือกแหล่งเพลงใน notch ให้ถูกแท็บ
• ใช้โหมด Incognito/Private: ค่าเริ่มต้นของเบราว์เซอร์อาจไม่อนุญาตส่วนขยาย
  ให้ทดสอบในหน้าต่างปกติก่อน
• โหลดไม่สำเร็จ: ตรวจว่าเลือกโฟลเดอร์ที่มี manifest.json จริง
• หลังอัปเดต AmpNotch: หากส่วนขยายมีรุ่นใหม่ ให้คัดลอกเนื้อหา BrowserExtension
  จากแอปรุ่นใหม่มาแทนในโฟลเดอร์เดิมที่ Documents แล้วกด Reload ของส่วนขยาย
  ที่หน้าจัดการ Extensions และรีโหลดหน้าเว็บเพลงอีกครั้ง

ข้อมูลที่ส่วนขยายใช้
--------------------
ส่วนขยายอ่านข้อมูลและควบคุมสื่อบนหน้าเว็บที่ได้รับสิทธิ์ แล้วส่งข้อมูลเพลง
ให้ AmpNotch ผ่านการเชื่อมต่อภายในเครื่องที่ 127.0.0.1:9876 พร้อมรหัสจับคู่
สิทธิ์เข้าถึงหน้าเว็บใช้เพื่อค้นหาและควบคุมตัวเล่นสื่อ ไม่ได้สะท้อนภาพวิดีโอ

คู่มือนี้เปิดอ่านได้แม้ไม่มีอินเทอร์เน็ต และเปิดอีกครั้งได้จาก
Settings → Music & browser → Extension setup guide

อ้างอิงขั้นตอน Load unpacked ของ Chrome:
https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world
